TWO OPERATORS, ONE MACHINE

Built for the moment a human hands over the controls.

OPERATOR / YOU

Sketch it by feel

Drag modules onto the canvas. Route data by connecting pins. Press RUN when the shape looks right — amber signals show exactly which path your data takes.

OPERATOR / AGENT

Drive it by tool calls

Your agent sees the same canvas through eight structured tools. No DOM scraping, no guessing at buttons — it adds nodes, routes wires, tunes configs, and runs the flow while you watch.

WHAT THE AGENT CAN TOUCH

Eight browser-native tools, declared by the page itself.

add_nodeDrops a new module onto the canvas
connect_nodesRoutes a wire from one pin to another
execute_workflowRuns the whole flow in dependency order
get_available_toolsDiscovers everything on offer
get_node_detailsInspects any module's wiring and config
update_node_configRetunes a module without rebuilding it
get_workflow_statusReads the board: modules, wires, counts
validate_workflowCatches broken wiring before a run
HOW A RUN GOES

Sketch, delegate, run.

Sketch it

Name a module, pick its type, drop it in. Wire the pins yourself until the flow reads the way you think.

Delegate it

Tell your agent what's missing. It answers with tool calls — add_node, connect_nodes — and you watch each one land on the canvas.

Run it

One press starts the sequence. Signals march across the wires, modules light up in order, and telemetry logs every step for both operators.
